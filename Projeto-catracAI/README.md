# Projeto CatracAI

Este é um projeto de aplicação web para reconhecimento facial, utilizando o Face-API.js. Ele pode ser usado para sistemas de controle de acesso ou outras aplicações que necessitem de detecção e reconhecimento facial onde tudo acontece de maneira offiline, salvando os dados no própio navegador! 

## Tecnologias Utilizadas

*   **Node.js**: Ambiente de execução JavaScript.
*   **Express.js**: Framework web para Node.js, usado para construir a API e servir arquivos estáticos.
*   **Face-API.js**: Biblioteca JavaScript para detecção e reconhecimento facial no navegador.
*   **HTML/CSS/JavaScript**: Para o frontend da aplicação.

## Instalação

Siga os passos abaixo para configurar e executar o projeto localmente:

1.  **Clone o repositório:**
    ```bash
    git clone <https://github.com/ronald2329/IaHub-documentation>
    cd Projeto-catracAI
    ```

2.  **Instale as dependências:**
    No diretório `Projeto-catracAI`, execute:
    ```bash
    npm install
    ```

## Uso

Para iniciar o servidor, execute o seguinte comando no diretório `Projeto-catracAI`:

```bash
node server.js
```

O servidor será iniciado em `http://localhost:3000`.

*   **Sistema da Catraca**: Acesse `http://localhost:3000/` para a página principal do sistema da catraca.
*   **Página de Registro**: Acesse `http://localhost:3000/register.html` para a página de registro de usuários.
*   **Outras funcionalidades**: Explore os arquivos na pasta `public` para entender as outras funcionalidades da interface.
